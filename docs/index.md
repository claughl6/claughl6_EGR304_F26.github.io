## Introduction

* This datasheet serves to document the engineering design and implementation process of the distance-sensing subsystem for Project SBWB (Self-Balancing Work Bench).

### Project Summary

Project SBWB is an automated, self-stabilizing platform designed to maintain a level working surface in dynamic or unstable environments, enabling users to perform precise operations without mechanical interference.
The distance-sensing unit operates as a core feedback mechanism alongside an Inertial Measurement Unit (IMU). While the IMU tracks tilt and velocity, the distance-sensing subsystem continuously measures surface height displacement and positional orientation relative to the base. This spatial data is conditioned, filtered, and transmitted across the microcontroller network to drive motor actuators for active, real-time stabilization.
